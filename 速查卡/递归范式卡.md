# 递归题核心要素（速查卡）

## 一、骨架：四个零件

| 零件 | 作用 | 例子 |
|---|---|---|
| **出口** base case | 最小情况直接给答案 | `n == 0 → 0`；`n < 10 → n` |
| **归约** reduce | 让参数变小 | `n // 10`、`n - 1`、`n - m`、`n - 2` |
| **本层贡献** | 这一层算出什么 | `n % 10`、`1 或 0`、一个 `print` |
| **合并 + return** | 本层 + 子问题结果 | `return 本层 + recurse(变小)` |

---

## 二、"数方案数"（树递归）三步

1. **分类**：把方案分成**互斥且穷尽**的两类 → 「**用至少一个 X**」+「**完全不用 X**」
2. **归约**：
   - 用 X → 规模减掉 X（`n - X`），X 不变（还能再用）
   - 不用 X → 规模不变，X **降一级**（`next_smaller(X)`）
3. **出口**：
   - `n == 0` → **1**（凑齐了，算一种）
   - `n < 0` → **0**（超了，无效）
   - 部件用尽（`m == 0` / 只剩 1 元）→ 0 或 1

→ 两类**相加**（分组计数用加法）。

---

## 三、什么时候需要内层 helper

**需要跨层携带多个状态**时：

| 场景 | 要带的状态 |
|---|---|
| 换零钱 | 剩余金额 + 当前面额 |
| `interleaved_sum` | 当前位置 + 当前该用哪个函数 |
| 汉诺塔 | n + 起点 + 终点 + 中转 |

## 四、常见死法（自查清单）

- [ ] 忘了 `return`（某个调用表达式单独占一行）
- [ ] 用累加变量跨层（`times = 0` 是每层自己的，不会共享）
- [ ] 递归调错函数（调了自己而不是 helper → 无限递归）
- [ ] **相乘**当成相加
- [ ] 缺 base case / 顺序错（负数、边界值）
- [ ] 变量遮蔽（参数被同名循环变量覆盖）
- [ ] 隐藏状态被多消费一次（骰子、策略调用次数）
- [ ] 库函数返回 `None` 没处理（`next_smaller_dollar(1)`）

## 五、写完自检五问

1. 最小情况是什么？我**手推**过 n = 0/1/2 吗？
2. 每次递归的参数**真的变小**了吗？（会不会无限递归）
3. **每条路径**都 `return` 了吗？
4. 两个分支**互斥且穷尽**吗？该加还是该乘？
5. 有没有依赖"被调用几次/调用顺序"的状态？

## 六、四个模板

```python
# 1) 一位一位剥（线性递归）
def sum_digits(n):
    if n < 10:
        return n
    return n % 10 + sum_digits(n // 10)

# 2) 两个分支（树递归）
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

# 3) 分类计数（树递归，换零钱同族）
def count_partitions(n, m):
    if n == 0:
        return 1
    elif n < 0:
        return 0
    elif m == 0:
        return 0
    return count_partitions(n - m, m) + count_partitions(n, m - 1)

# 4) 缩小规模 + 两次递归（汉诺塔，打印而非返回）
def move_stack(n, start, end):
    if n == 1:
        print_move(start, end)
        return
    other = 6 - start - end          # 三根柱子编号 1,2,3
    move_stack(n - 1, start, other)
    print_move(start, end)
    move_stack(n - 1, other, end)
```

## 七、调试手法

1. **打印每层状态**：`print("DEBUG:", n, ...)`（ok 会忽略 `DEBUG:` 开头的行）
2. **先手推** n = 1, 2, 3，写出每层的返回值，和程序对照
3. **缩小规模**：用 `n = 3` 而不是 `n = 100` 去跑
