# 速查卡（索引）

放"随时要翻"的速查资料。和 `进度.md` / `卡点.md` 的区别：

| 文件 | 性质 |
|---|---|
| `进度.md` | 记录做了什么 |
| `卡点.md` | 记录踩过的坑 |
| **`速查卡/`** | **可复用的范式、命令、模板** |

## 写作约定（保持一致才好翻）

每张卡尽量包含这几块：

1. **一张总表**（概念 → 一句话）
2. **核心步骤**（3–5 步，可照做）
3. **常见死法**（带复选框）
4. **自检问题**（写完问自己）
5. **可抄的模板**（代码片段）
6. **调试手法**

命名：`<主题>卡.md`，例如 `环境图卡.md`。
